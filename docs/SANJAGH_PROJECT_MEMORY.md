# SANJAGH PROJECT MEMORY

## Project
Name: Sanjagh (سنجاق)
Repository: turkan2018/sanjagh-app

## Vision
Sanjagh is planned as a professional industrial and commercial real estate platform, focused on large assets, factories, industrial land, warehouses, investment opportunities and intelligent property discovery.
